# Generative AI Research Project

## Project Overview
This repository is used to store, organise, and manage research data related to the topic "Using Generative AI Tools – Boon or Bane".

## Project Structure
- Literature Review: contains journal articles and research notes
- Quantitative Data: includes survey data and analysis files
- Qualitative Data: includes interview data and transcripts
- Drafts and Reports: contains draft reports and final documents
- Additional Materials: includes supporting files such as images and other resources

## How to Navigate
Each folder represents a specific type of research data. Users can open the folders to find relevant files based on their category.

## Collaboration
Team members can contribute by uploading files, editing content, and using version control. All changes are tracked through GitHub commits to ensure transparency and data integrity.
